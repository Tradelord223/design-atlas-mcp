Install the local server
Use Node.js 22.16 or newer. Download the release package, then run this command in the folder containing it.
Download package ↓
npm install -g ./design-atlas-mcp-1.2.0.tgz

    
Add it to your MCP client
Run this in your terminal, then open a fresh chat.
codex mcp add design-atlas -- design-atlas-mcp
If a desktop client cannot find the command
Run npm root -g to find the global package folder. Set the client command to node and its argument to the absolute path of design-atlas-mcp/src/cli.js inside that folder.
