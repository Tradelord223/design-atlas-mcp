# STRATA original-first field study

## Original and scope

The source is [STRATA Agrisystems v1](https://strata-agrisystems.raqmanplentiful.chatgpt.site/), inspected as a live public page on 18 November 2026. This study reproduces the original header, aerial hero, ambient telemetry, three named sensors, intelligence triptych, and reference footer. The navigation links open the corresponding sections of the complete original site.

The full page remains available through “Open the complete original.” This excerpt covers the hero and intelligence overview. Its reading dialogs, perspective stories, forecast notes, and year-specific chart controls use the original text and values.

The values 34.2%, 0.71 and 27.8°C belong to the original illustrative field snapshot dated 27 August 2024. The original forecast notes explain the conceptual 2024–2034 values and the separate +42% artwork annotation.

## The field-note enhancement

The actual Design Atlas MCP operation `apply_reference_detail` selected the existing `.sensor.moisture`, `.sensor.ndvi` and `.sensor.canopy` buttons, with one expected match each. It returned the supplied HTML unchanged and generated the separate `field-note.css` and `field-note.js` artifacts used here.

`integration.json` records the reference version, three matched controls, preservation hash, controller API and behavior. The generated tooltip palette has measured text contrast of 12.47:1. The descriptions use sentences from the original reading context.

The enhancement adds one anchored tooltip on hover or keyboard focus. Escape dismisses it, the pointer can enter it, and the existing click/tap action opens the full reading. The comparison switch disables the generated controller for the Original state. The wrapper forwards Escape and focus changes across its first-party iframe boundary so dismissal also works after using the outside controls.
